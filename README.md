# Angel Designs LA — Static Portfolio Site

A modern, sleek, tech-forward HTML/CSS/JS website for a political graphic design studio.

## Edit checklist

1. Replace `your.email@example.com` in `index.html`.
2. Replace the placeholder SVGs in `assets/work/` with your real graphics.
3. Update each work card title, category, and description.
4. Add real case studies once you know which projects you want to feature.
5. Push to GitHub and deploy through Vercel, or deploy with the Vercel CLI.

## Recommended image naming

```txt
assets/work/la-mayor-results.png
assets/work/cd4-precinct-map.png
assets/work/ca-governor-simulation.png
assets/work/turnout-scenario-card.png
```

## Local preview

Open `index.html` directly in your browser, or run a simple local server:

```bash
python -m http.server 3000
```

Then visit `http://localhost:3000`.

## Deploy with Vercel CLI

```bash
npm i -g vercel
vercel --prod
```

## Deploy with GitHub + Vercel

1. Create a GitHub repository.
2. Push this folder to GitHub.
3. Import the repository in Vercel.
4. Vercel will redeploy every time you push changes.
